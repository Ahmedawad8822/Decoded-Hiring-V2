# Security policy

Report suspected vulnerabilities using [GitHub private vulnerability reporting](https://github.com/Ahmedawad8822/Decoded-Hiring-V2/security/advisories/new).
Open the repository's **Security → Advisories → Report a vulnerability** form.

Include the affected revision, reproduction steps, impact and a minimal example
using synthetic data. Do not put credentials, private user data or exploit
details in public issues, discussions or pull requests.

Security fixes target the current `main` branch. Older revisions do not have a
separate security maintenance policy. Reports are reviewed privately; no
response-time guarantee is currently offered.
